# PWA audit, 2026-11-03

App: Jasette. Published at https://robertwalterj.github.io/jasette/ (one shared origin with Robert's other apps).

Jargon: a "service worker" is the small script that lets the app work offline. A "cache" is the phone's saved copy of files. "Manifest id" is the name Chrome uses to tell installed apps apart.

## What was checked

The nine shared-origin rules: manifest id, scope and start_url, cache cleanup, no global caches.match(), manifest never cache-first, icons, storage names, big precache, and navigation handling. Source files and the generated docs/ or site/ folder were both read.

## Findings

| Rule | Result |
|---|---|
| 1 Manifest id | OK. id is /jasette/. |
| 2 Scope and start_url | OK. Both are ".". |
| 3 Cache cleanup | OK. Deletes only jasette-v-* that are not current. The audio caches are kept on purpose. |
| 4 Global caches.match() | OK. Not used. |
| 5 Manifest not cache-first | OK. The worker skips it. |
| 6 Icons | OK. 192, 512 and maskable 512 with the art inset. |
| 7 Storage names | OK. Key jasette.v1. Caches start with jasette-. No sign of hokgong keys in the code. |
| 8 Big precache | OK. Small shell, each file added on its own. |
| 9 Navigation handling | BROKEN (low risk). Every page load that returned ok was saved as index.html, even for other addresses in scope. Fixed in source: only the app home (the folder or index.html) may replace it. |

## What I changed

app/sw.js: in the page branch, index.html is now only replaced when the address is the app home.

I could NOT rebuild docs/. The corpus file app/data/deck.json is not in the repo, so `npm run build` stops at its first check (build/verify.mjs). So docs/sw.js still has the old behaviour. I did not hand-edit it.

Cache name: the build stamps it from the scripts, styles and deck only, so it will not change from this fix alone. Phones still pick up the new worker because the file contents changed.
